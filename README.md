
# 📰 Fake News Detection using ISOT Dataset  

This project focuses on detecting **fake news articles** using **Natural Language Processing (NLP)** and **Machine Learning** techniques. The ISOT dataset, containing real and fake news articles, is used for training and evaluation.  

---

## 📂 Dataset  

The project uses the **ISOT Fake News Dataset**:  

Dataset Link : https://drive.google.com/drive/folders/1dX2ax9NkPFgLMl7wMdEHFjWGDggbvslK?usp=drive_link

- **True.csv** → Genuine news articles  
- **Fake.csv** → Fake news articles  

Each article is labeled as:  
- **0 = Fake**  
- **1 = Real**
